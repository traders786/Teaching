# upspeaq — Communication & Confidence Platform

> **Empowering Young Minds with Voice, Courage & Conviction**  
> An interactive public speaking, debate, and spoken English communication platform tailored for school students (Classes 4–12).

---

## 🌟 Programs Offered
- **1-Month Starter Cohort** (₹1,999 / month) — 12 Live Classes (3/week), foundation fluency, vocabulary & stage confidence.
- **3-Month Flagship Masterclass** (₹4,999 Total) — 36 Live Classes (3/week), debate logic, extempore, graduation showcase & verified certificate.
- **1-on-1 Individual Classes** (₹5,000 / month) — 12 Dedicated 1-on-1 Private Sessions with a senior speech coach, custom pacing & flexible timings.
- **100% Free Demo Session** included on all programs.

---

## 🚀 Key Features
- **Strict 8-Student Batches**: Maximizes speaking time with at least 15 minutes of individual stage practice per class.
- **Parent WhatsApp Diagnostic Reports**: Weekly structured assessments delivered directly to parents.
- **Full Staff & Admin Operations Portal**: Real-time lead CRM, demo scheduling, student rosters, batch capacity monitors, fee collection links, and audit logs.
- **Interactive Parent Payment Portal**: Invoice generation and payment tracking.

---

## 🛠️ Technology Stack
- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Backend & API**: Node.js, Express, SQLite (`node:sqlite`), JWT Authentication
- **Build Tool**: Vite 6, Rollup WASM

---

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run the full-stack dev server
npm run dev

# 3. Open in your browser
http://localhost:3000
```
